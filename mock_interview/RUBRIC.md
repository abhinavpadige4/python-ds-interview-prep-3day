## Total: ___/100

### Score bands

- **90–100:** Interview-ready. Go get that offer.
- **75–89:** Solid. Review weak areas, do one more mock.
- **60–74:** Needs work. Revisit the patterns you missed.
- **<60:** Not ready. Extend prep by 2–3 days.

---

## Common deductions

- **Didn't restate the problem:** -5
- **Jumped to code without explaining:** -5
- **Wrong complexity analysis:** -5
- **Missed edge cases (empty input, single element):** -5
- **Code doesn't run:** -10
- **Couldn't answer concept questions:** -5 each
