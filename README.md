## How to use

1. Read `PLAN.md` first — it has the exact hourly schedule.
2. Open the Notion page and check off problems as you go.
3. For each problem: read the problem statement on LeetCode, try for 20–25 min, then read the solution here.
4. Day 3 ends with a 90-minute mock interview — see `mock_interview/`.
